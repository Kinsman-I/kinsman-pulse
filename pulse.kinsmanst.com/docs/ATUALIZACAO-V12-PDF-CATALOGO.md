# Atualização V12 - exportação e catálogo completo

Esta versão não exige alteração no banco de dados.

## Exportação

Na edição de uma ficha de treino ou de um plano alimentar, use o botão **Exportar PDF**.
O sistema abre uma versão A4 com:

- logo e marca do profissional;
- nome, especialidade, registro, contato e WhatsApp do profissional;
- nome, idade, altura, peso, meta e contato do aluno;
- exercícios, séries, repetições, carga, descanso e orientações;
- ou refeições, horários, alimentos, substituições e orientações gerais.

Na janela aberta, escolha **Salvar como PDF / Imprimir**. O navegador permite salvar o
arquivo em PDF ou enviar para uma impressora.

## Catálogo

Na tela Catálogo de exercícios, o botão **Adicionar todos os exercícios** copia toda a
Biblioteca Kinsman para o catálogo particular do profissional. Exercícios já existentes
não são duplicados.
